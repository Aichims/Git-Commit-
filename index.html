Comment faire un commit sur Git ?

Une méthode simple et visuelle pour vérifier, préparer et enregistrer tes modifications en confiance : observe, prépare, puis enregistre.

Objectifs

À la fin, tu sauras enregistrer ton travail dans l'historique Git.

Pour les étudiants et débutants qui connaissent les bases de la programmation, ont déjà entendu parler de Git ou GitHub, mais ne savent pas toujours quelle commande utiliser, ni dans quel ordre. Budget : 0 € de logiciel, tout est gratuit.

Programme

3 modules, une vidéo chacun.

Module 1

Vérifier les modifications

Repère les fichiers modifiés et les fichiers non suivis avant de créer un commit.

  • Lancer git status dans le dossier du projet
  • Lire Changes not staged for commit et Untracked files
  • Décider quoi inclure dans le prochain commit
Module 2

Préparer les fichiers

Choisis précisément les fichiers à inclure grâce à la zone de préparation (staging area).

  • Préparer un fichier précis avec git add index.html
  • Comprendre le risque de git add .
  • Vérifier le résultat avec git status
Module 3

Créer le commit

Enregistre les modifications préparées avec un message clair, puis retrouve-les dans l'historique.

  • Écrire git commit -m "message" avec un message pertinent
  • Contrôler l'historique avec git log --oneline
  • Retirer un fichier avec git restore --staged
